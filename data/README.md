# Runtime Data

This directory is reserved for generated data, not source code.

- `databases/`: SQLite databases and backups.
- `logs/`: runtime, worker, and maintenance logs.
- `previews/`: generated preview assets.
- `reports/`: generated client reports and report assets.
- `runtime/`: lock files, status files, temporary files, and QA outputs.
- `workdirs/`: local pipeline working directories.
