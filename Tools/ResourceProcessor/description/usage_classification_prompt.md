# 游戏资源用途分类规则

分类只表达资源导入游戏后的空间形态与直接用途。
不要把对象名称、主题、风格、颜色、材质、时代、文件格式、制作工具写成分类。

## space

只能选一个：

- `2D`：平面图像、Sprite、UI、序列帧、Tilemap/Tileset、二维背景、二维特效。
- `3D`：三维模型、三维骨骼、三维场景结构、PBR 材质、Skybox、三维粒子。
- `通用`：不依赖 2D/3D 空间，典型是字体和音频。
- `混合`：同一资源不可拆分，且同时含可独立使用的 2D 与 3D 内容。
- `不确定`：证据不足，无法判断空间形态。

## category 和 subcategories

`category` 只能选一个；`subcategories` 只能从所属 `category` 下选择，通常不超过三个。

- `角色`：承担角色身份，或构成、驱动、表现角色。
  小类：人物、动物、怪物、机器人、机甲、角色部件、服装、动作、表情、其他。

- `环境`：构成游戏世界、场景空间、地貌、建筑、自然环境或视觉背景。
  小类：建筑与结构、地形、自然景观、植被、水体、天空、道路、室内场景、场景背景、其他。

- `界面`：用于屏幕空间交互、信息展示、状态反馈、菜单系统或操作引导。
  小类：图标、按钮、面板、菜单、弹窗、HUD、状态条、输入控件、提示、其他。

- `物件`：可作为独立对象放入游戏世界，但不是角色、环境主体、界面或特效。
  小类：道具、装备、武器、载具、家具、机关、可交互物、摆件、其他。

- `特效`：用于短暂、动态或持续视觉反馈，按使用时机和功能分类。
  小类：环境特效、技能与攻击特效、弹道特效、命中特效、状态特效、界面特效、转场特效、其他。

- `文字与字体`：提供字体、字形或可独立使用的设计文字。
  小类：字体、字形集、标题字、数字字形、其他。

- `音频`：提供游戏中的声音内容，通常 `space=通用`。
  小类：音乐、环境声、界面音效、战斗音效、技能音效、交互音效、角色语音、音效、其他。

- `其他`：用于占位/辅助资源，或以上大类都无法表达直接用途时使用。
  小类：占位/辅助资源、其他。

## 关键边界

- 先使用现有分类，能表达直接用途时不要选 `其他`。
- 如果已经选择了明确小类，不要同时选择 `其他`；`其他` 只在没有任何明确小类适用时单独使用。
- `不确定` 只用于 `space`，不是 `category`。
- 头像、武器、技能图片如果作为 UI 使用，归 `界面-图标`。
- `right`、`left`、`appear`、`disappear`、`open`、`opening`、`closed`、`closing`、`wrong`、`right/wrong` 等文件名状态词，只能作为弱线索；不要仅凭这些词把资源归为 `角色-动作`。只有画面主体明确是角色身体、角色部件、角色姿态或角色动画时才归角色动作。
- 数字、徽章、笔记、标记、圆形符号、状态符号等 UI 图标即使带有 `appear`、`right`、`wrong` 等状态名，也优先归 `界面-图标` 或 `界面-界面特效`，不要误归角色。
- 陷阱、尖刺、开关、门控、传送器等带危险、触发或交互功能的世界对象，优先归 `物件-机关` 或 `物件-可交互物`，不要仅因它们放在场景里就归 `环境-场景背景`。
- 瓶子、箱子、门、机关、容器等独立物件的打开、关闭、出现、消失、数量变化或状态帧，优先保持为 `物件-道具` / `物件-可交互物` / `物件-机关`；只有画面主体主要是粒子、光效、爆炸、拖尾、冲击或没有稳定物件主体时才归 `特效`。
- 完全透明、无可见像素、None 空图层、空白占位、全黑或全白占位/遮罩/填充图块，归 `其他-占位/辅助资源`，不需要填写 `suggestion`。
- 除全黑、全白外，其他颜色的纯色图块交给模型根据可见颜色、资源类型与上下文判断，不要自动归占位。
- 门、钥匙、金币、宝箱、剑、树等具体对象不要新增为分类，应归入现有小类。
- 火焰、烟雾、魔法、科幻、像素风等内容或风格不要作为分类。
- PNG、WAV、FBX、Unity、RPG Maker、PBR、分辨率、视角等格式、工具、技术不要作为分类。
- 选择小类 `其他` 时必须填写 `suggestion`；选择 `其他-占位/辅助资源` 时 `suggestion=null`。
